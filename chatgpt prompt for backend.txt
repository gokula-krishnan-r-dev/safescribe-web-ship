RENAL DOSING POLICY:
- SafeScribe uses eGFR as the operational renal dosing value.
- Renal dosing basis must therefore be eGFR whenever structured renal adjustment is generated.
- Renal source basis records the renal measure used by the underlying authoritative source.
- If the authoritative source uses CrCl, set Renal source basis: CrCl.
- If the authoritative source uses eGFR, set Renal source basis: eGFR.
- If another renal metric is explicitly used, set Renal source basis: OTHER.
- If no renal adjustment applies, set Renal source basis: NONE, Renal dosing basis: NONE, and Renal dosing rules: [].
- Do not claim that the manufacturer used eGFR when the source actually used CrCl.
- SafeScribe may operationalize supported adult renal dose-adjustment bands using eGFR for the pharmacist-facing workflow.
- Renal reason must describe the pharmacist-facing eGFR thresholds and corresponding regimens.
- Renal dosing rules must contain the same eGFR thresholds and corresponding regimens.
- Use reported eGFR in mL/min/1.73 m² unless a pathway-specific validated rule states otherwise.
- Include all clinically relevant eGFR thresholds and exact adjusted regimens when supported.
- Include the normal-function regimen when useful for comparison.
- Include hemodialysis instructions only when supported.
- Do not invent dialysis instructions.
- If renal function is rapidly changing, acute kidney injury is suspected, dialysis circumstances are uncertain, eGFR is close to a dosing threshold, or indexed eGFR may not appropriately represent clearance because of markedly unusual body size, state that pharmacist review is required.
- Do not automatically extrapolate adult renal rules to pediatric patients unless validated pediatric renal dosing is available.
- When an adjusted dose requires a different product strength, preserve the required clinical dose and require appropriate product selection rather than assuming the current product can be divided.

- Do not use comments.
- Use null for an unbounded minimum or maximum.
